# Netflix Clone

A modern Netflix Clone built using React.js, Vite, and Docker.

## Features

- Netflix-inspired user interface
- Responsive design for all devices
- Movie search functionality
- Trending movies section
- Fast performance with Vite
- Docker containerization

## Tech Stack

- React.js
- JavaScript
- CSS
- Vite
- Docker

## Installation

1. Clone the repository

```bash
git clone https://github.com/veena172/netflix-clone.git
```

2. Navigate to the project folder

```bash
cd netflix-clone
```

3. Install dependencies

```bash
npm install
```

4. Run the project

```bash
npm run dev
```

## Docker Setup

Build Docker Image:

```bash
docker build -t netflix-clone .
```

Run Docker Container:

```bash
docker run -p 4173:4173 netflix-clone
```
